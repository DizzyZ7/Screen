# Screen

Картинка поверх любого обычного окна Windows — как прозрачный лист на холсте.
Подходит для тренировки контуров: открой референс, совмести его с холстом,
настрой непрозрачность и обводи в своем редакторе.

Screen показывает референс. Линии и раскрашивание сохраняются в редакторе под ним:
Paint, Krita, Photoshop, браузерном холсте или другой программе рисования.

## Скачать и открыть

[Скачать Screen 0.1.0 для Windows x64](https://github.com/DizzyZ7/Screen/releases/download/v0.1.0/Screen-windows-x64.zip)
· [Все версии](https://github.com/DizzyZ7/Screen/releases)
· [Проверки и сборки](https://github.com/DizzyZ7/Screen/actions/workflows/ci.yml)

1. Скачай `Screen-windows-x64.zip` из Releases. Если первая сборка еще идет,
   ее состояние видно в Actions; успешные проверки предшествуют публикации.
2. Полностью распакуй архив и открой `Screen/Screen.exe`.
3. Python устанавливать не нужно. Сохраняй `Screen.exe` вместе с папкой `_internal`.

Предварительная версия для Windows 10/11 x64. Установка и права администратора не нужны.

## Первая обводка

1. Открой редактор и создай холст.
2. В Screen нажми «Открыть…» либо скопируй картинку в браузере и нажми
   «Вставить» / `Ctrl+V` в панели Screen. Также можно перетащить файл в панель.
3. В режиме «Настройка» передвинь картинку мышью. Колесо меняет масштаб
   относительно курсора. За ручки по краям можно менять размер.
4. Выключи «Сохранять пропорции», если нужно отдельно расширить или сузить
   картинку под холст. Ширину и высоту можно ввести точно в пикселях.
5. Поставь непрозрачность примерно 25–50%: через картинку будет виден твой рисунок.
6. Нажми «Начать обводку». Рамка исчезнет; мышь, перо и клики проходят в редактор.
7. Рисуй. Через `Ctrl+Alt+F9` можно временно убрать референс и посмотреть результат.
   Для изменения его положения нажми `Ctrl+Alt+F8`.

Панель Screen — самостоятельное окно: ее можно передвинуть, свернуть или скрыть
через `Ctrl+Alt+F10`. Значок Screen в трее возвращает панель. Закрытие панели крестиком
или команда «Завершить Screen» убирает все прозрачные окна и завершает приложение.

## Управление

| Действие | Управление |
| --- | --- |
| Настройка / обводка, из любого редактора | `Ctrl+Alt+F8` |
| Показать / скрыть референс | `Ctrl+Alt+F9` |
| Показать / скрыть панель | `Ctrl+Alt+F10` |
| Открыть картинку / вставить | `Ctrl+O` / `Ctrl+V` в Screen |
| Сохранить / открыть проект | `Ctrl+S` / `Ctrl+Shift+O` в панели |
| Перенос | Левая кнопка мыши на картинке в настройке |
| Масштаб | Колесо над картинкой или поле «Масштаб» |
| Непрозрачность | Ползунок или `Ctrl` + колесо в настройке |
| Размер | 8 ручек; `Shift` временно меняет сохранение пропорций |
| Точный сдвиг | Стрелки на выбранной картинке: 1 px, `Shift`: 10 px |
| Начать обводку с выбранной картинки | `Esc` |

Глобальные клавиши регистрируются через Windows `RegisterHotKey`. Если сочетание
занято, панель сообщает об этом; управление остается через кнопки и трей.
Screen не перехватывает и не записывает остальные клавиши.

## Возможности

- PNG с прозрачностью, JPEG с ориентацией EXIF, WebP, BMP, TIFF, первый кадр GIF.
- Непрозрачность самой картинки 0–100%, независимая от панели.
- Размер с пропорциями и без, масштаб, поворот на любой угол, отражение по обеим осям.
- «По центру», «Вписать в экран» и выбор монитора. Координаты и размеры — логические
  пиксели Windows/Qt, учитывающие масштаб интерфейса дисплея.
- Отдельная поверхность на каждый монитор; референс можно двигать между ними.
- Проект `.screenref` хранит картинку внутри файла, положение, размеры, поворот,
  отражения, непрозрачность и режим пропорций. Исходный PNG/JPEG рядом не нужен.
- Никакого сервера, аккаунта, API или сетевых запросов. Картинки остаются на ПК.
  Без явного сохранения проекта Screen запоминает только настройки и позицию панели.

## Если что-то непонятно

- В браузере выбирай «Копировать изображение». «Копировать адрес изображения» дает
  ссылку; Screen не скачивает адреса автоматически. Альтернатива: сохрани картинку
  на ПК и открой как файл. Скриншот из `Win+Shift+S` тоже можно вставить.
- Видишь картинку, но не можешь рисовать под ней — включи «Обводку».
- Хочешь переместить картинку — верни «Настройку» через `Ctrl+Alt+F8`.
- После смены монитора выбери нужный экран и нажми «По центру» или «Вписать в экран».
- 0% непрозрачности полностью скрывает картинку, но в настройке ручки остаются видимыми.
- Обводка не переносит референс в файл рисунка. Это отдельный экранный слой;
  обычный скриншот, наоборот, может захватить его вместе с рабочим столом.

Пределы: входной файл/проект до 64 MiB, изображение до 32 млн пикселей и 16384 px
по стороне; отображаемая сторона 24–16384 логических px. Чрезвычайно узкие картинки,
не помещающиеся в эти пределы с сохранением пропорций, нужно дополнить полями.
Поврежденный файл не заменяет текущую картинку. Проект записывается атомарно.

Окно предназначено для обычного рабочего стола. Эксклюзивный полноэкранный режим,
защищенные экраны Windows и отдельные режимы драйверов планшетов могут вести себя
иначе. Сборки пока без цифровой подписи. Реальная работа в твоем редакторе,
на нескольких мониторах с разным масштабом и с планшетом требует проверки на ПК.

## Запуск из исходников

Нужен Python 3.12 x64 или новее. Из корня проекта в PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m screen_overlay
```

Файл можно передать при запуске:

```powershell
.\.venv\Scripts\python.exe -m screen_overlay "C:\Pictures\reference.png"
```

## Сборка и проверки

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m ruff format --check .
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
& .\scripts\build_windows.ps1
```

В последней команде `python` должен указывать на нужное окружение. Можно сначала
активировать `.venv` либо запускать сборку из терминала с Python 3.12 в PATH.
Результат: `dist/Screen/Screen.exe`, ZIP и контрольная сумма SHA-256.

GitHub Actions запускает тесты на Linux и реальном Windows runner. Windows-тесты
проверяют native-стили, доставку `WM_HOTKEY`, конфликт сочетаний и фактический
проход мышиного клика через референс в тестовое нижнее окно. Затем CI собирает
portable-папку и запускает именно упакованный exe с `--smoke-test`.
Успешная сборка из `main` публикуется как предварительная версия в Releases;
номер версии берется из `pyproject.toml`. Повторный запуск не заменяет уже выпущенную версию.

Linux используется для разработки и Qt offscreen-тестов:

```bash
QT_QPA_PLATFORM=offscreen python -m unittest discover -s tests -v
QT_QPA_PLATFORM=offscreen python -m screen_overlay --smoke-test
```

Полные Win32-возможности включаются только на Windows. Физическое перо и конкретные
редакторы автоматические тесты не проверяют.
