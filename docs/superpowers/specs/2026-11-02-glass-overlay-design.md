# Screen: прозрачный референс для обводки

## Назначение

Димаш хочет открывать картинку поверх редактора на Windows, совмещать ее с
холстом и учиться рисовать по контуру. Рисование остается в редакторе под
Screen. Приложение не генерирует штрихи и не управляет чужими процессами.

## Требования

- Windows 10/11 x64, отдельная portable-папка с Screen.exe, без Python у пользователя.
- Картинка из файла, перетаскивания или Ctrl+V (данные изображения либо скопированный локальный файл).
- Окно без подложки поверх остальных окон. Меняется непрозрачность самой картинки (0–100%).
- Режим настройки: перенос мышью, колесо с масштабированием относительно курсора,
  восемь ручек размера, стрелки для точного сдвига. Пропорции сохраняются по умолчанию;
  можно выключить ограничение и менять ширину/высоту независимо.
- Панель: размеры, масштаб, поворот, отражения, центрирование на выбранном мониторе,
  сброс преобразований, скрытие референса. Единицы расположения — логические пиксели Qt.
- Режим обводки: изображение остается видимым, все клики/перо идут в приложение под ним.
  Панель независима, ее элементы управления продолжают работать.
- Ctrl+Alt+F8 — настройка/обводка; Ctrl+Alt+F9 — видимость; Ctrl+Alt+F10 — панель.
  Использовать RegisterHotKey без перехвата/записи остальных клавиш.
- Трей с восстановлением панели и выходом. Закрытие панели завершает весь процесс.
- Несколько мониторов и разные DPI: прозрачное окно на каждом мониторе,
  одна общая геометрия изображения в логических координатах Qt.
- Явное сохранение/открытие проекта .screenref с встроенным PNG и расположением.
  Автоматически запоминать только настройки, не содержимое буфера и не изображение.
- Неверные, чрезмерно большие изображения и поврежденные проекты дают понятную ошибку,
  не заменяя текущий референс. Не скачивать адреса из буфера автоматически.

## Выбор реализации

Мой выбор: Python 3.12 + Qt 6 (PySide6 Essentials), Win32 через ctypes,
PyInstaller onedir. Это позволяет проверять геометрию и GUI в Linux, а реальную
Windows-интеграцию и portable-сборку — на windows-latest в GitHub Actions.
C#/WPF потребовал бы отдельного Windows-окружения для большинства проверок;
Electron добавляет браузерный runtime для очень небольшого приложения.

## Устройство

- geometry.py: независимая от Qt геометрия, пределы, преобразования, resize с неподвижным противоположным краем.
- images.py / project.py: ограниченная загрузка изображений, ориентация EXIF,
  чтение/атомарная запись проектов, сохранение alpha.
- overlay.py: рисование картинки и ручек, обработка мыши/колеса/стрелок.
- native.py: Win32 стили пропуска ввода, глобальные клавиши, снятие регистрации.
- panel.py: русскоязычная панель, не зависящая от прозрачности картинки.
- app.py: состояние, экраны, трей, маршрутизация действий, восстановление после смены мониторов.

## Границы проверки

Тесты геометрии и Qt offscreen обязательны локально. На Windows отдельно проверять
native-стили, WM_HOTKEY и фактический проход клика в нижнее окно. После упаковки
запускать exe в smoke-режиме. Проверку в конкретном редакторе и с физическим
графическим планшетом обозначать отдельно от автоматических тестов.
