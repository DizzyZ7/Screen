Первая предварительная версия Screen для Windows 10/11 x64.

- Прозрачный референс поверх редактора, сквозные клики в режиме обводки.
- Файлы с ПК, перетаскивание и вставка картинки из буфера.
- Размер, масштаб, прозрачность, поворот и отражение.
- Глобальные клавиши, трей, несколько мониторов, проекты .screenref.

Скачай Screen-windows-x64.zip, полностью распакуй и запусти Screen/Screen.exe.
Python и установка приложения не нужны. Не выноси exe из папки с _internal.

Ctrl+Alt+F8 — настройка/обводка; Ctrl+Alt+F9 — видимость картинки;
Ctrl+Alt+F10 — панель. Подробности в README.md внутри архива.

Сборка проходит Linux/Windows тесты и проверку запуска упакованного exe.
Совместимость с конкретными редакторами, смешанным DPI и физическими
графическими планшетами требует проверки на пользовательском ПК.
